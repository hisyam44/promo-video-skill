# Neon Dodge

A tiny neon arcade game that runs in any browser. Dodge the falling blocks, grab the glowing
orbs for points, and dash out of trouble. How long can you survive?

- Move: Arrow keys or A / D
- Dash: Space
- Start / restart: Enter
- Phones and tablets: hold the left or right half of the screen to move, swipe up to dash, tap to start

Plain HTML + canvas, no build step. Open `index.html` or serve the folder.
