# Rendering with Remotion

[Remotion](https://www.remotion.dev) renders React components to MP4, frame by frame, in
headless Chrome. The skill ships a complete template in `templates/remotion/`, and
`build_remotion.mjs` turns a storyboard into a ready-to-render project.

**License:** Remotion is free for individuals and companies of up to 3 people. Larger
companies need a company license (remotion.pro). Mention this when the user works for a
bigger organisation.

## Workflow
```bash
node $S/build_remotion.mjs promo/storyboard.json     # -> promo/remotion/ (installs on first run)
cd promo/remotion
npx remotion still Promo ../out/check.png --frame 90 # spot-check any frame
npm run render                                       # -> promo/out/promo.mp4
npm run render:vertical                              # -> promo/out/promo-9x16.mp4 (1080x1920)
npm run render:square                                # -> promo/out/promo-1x1.mp4  (1080x1080)
npm run render:landscape                             # -> promo/out/promo-16x9.mp4 (1920x1080)
```
- `Promo` renders at the storyboard's own `width`×`height`. The other compositions reflow the
  same scenes, so a phone sits beside the text on 16:9 and below it on 9:16.
- Faster previews while iterating: `npx remotion render Promo ../out/draft.mp4 --scale 0.5 --crf 28`.
- Render a single scene with `--frames=120-240`.
- Interactive preview for the user: `npx remotion studio`. It blocks the terminal, so run it
  in the background and stop it afterwards.
- A 17 s 1080p render takes about 2.5–4 minutes on an M1. `--concurrency 100%` uses every core.
- Disk: each project's `node_modules` is about 550 MB. `remotion.browser.json`, written by the
  build script, points Remotion at Playwright's headless Chrome, so it doesn't download its
  own 570 MB copy. Delete `promo/remotion/node_modules` when the user is done; the next build
  reinstalls it.
- After editing `storyboard.json` or retaking captures, run `build_remotion.mjs` again. It
  refreshes `public/` and the fonts in seconds and never reinstalls unless `package.json`
  changed.

## Template layout
| file | what's in it |
|---|---|
| `src/Root.tsx` | Registers the compositions and reads `public/storyboard.json` |
| `src/Promo.tsx` | All scene types, layouts (split, stack, gallery), background, transitions and audio |
| `src/devices.tsx` | Browser, plain, phone and tablet frames: geometry, status bar, Dynamic Island or punch-hole, home indicator, store badges |
| `src/types.ts` | Storyboard types |
| `src/fonts.generated.ts` | Brand fonts, generated by the build script; don't edit by hand |

**Edits are preserved.** The build script records the hash of each template file it copies.
On later builds, files you haven't touched are upgraded to the newest skill template. Files
you edited are kept, and you get a warning. `--reset-template` overwrites them.

## Rules when editing
- Every animation is driven by `useCurrentFrame()` with `interpolate`/`spring`. Never use
  CSS transitions, `setTimeout` or `Math.random()`: renders are frame-by-frame and parallel.
- Use `staticFile()` for files in `public/`. Use `<OffthreadVideo>` for footage
  (`trimBefore` takes frames), `<Img>` for images, and `<Audio>` for sound.
- Keep scene layout in the scene components and device drawing in `devices.tsx`.
- Run `npx tsc --noEmit` before rendering. Type errors are quicker to catch there than in a
  failed render.
- More Remotion know-how: the official agent skills can be installed with
  `npx skills add remotion-dev/skills`.

## Troubleshooting
| symptom | fix |
|---|---|
| "Version mismatch" | All `remotion` and `@remotion/*` packages must be the exact same version, with no `^` |
| Black or frozen clip | The clip is shorter than `from + duration` (the build warns), or a codec Chrome can't decode. Run `ff.sh normalize` on it. |
| Wrong font | The family name isn't a Google Font Remotion knows. Check the build output's `fonts` line and warnings. |
| Chrome download fails | `npx remotion browser ensure` |
| Out of memory or very slow | `--concurrency 2`, or close other apps |
